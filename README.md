# anotado-web
Web interface for the Anotado application (family finances) built with React.

## Stack
React 19, TypeScript, Vite, Tailwind 4, React Router 7, TanStack Query, Recharts, Axios.

## Running locally
```bash
npm install
npm run dev     # development server
npm run build   # type-check (tsc -b) and production build
npm run lint
```

## Environment
- `VITE_API_BASE_URL`: address of the Anotado API (for example `http://localhost:3000` when the API runs locally).
